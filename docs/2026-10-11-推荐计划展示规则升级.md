# 推荐计划展示规则升级（iter-017）

- 日期：2026-10-11 下午
- 触发：晚餐实弹演示后用户三点反馈——① 每类履约只推一种太少，且方案确定前应先确认人数和预算；② 最推荐的应放第一个；③ 套餐不展开组成，用户看不出买了啥（"麦辣鸡腿堡四件套包含啥？"）

## SKILL.md 新增三条展示规则（能力一第 5 步）

1. **规则 A · 方案前置问询**：记忆库没答案时，出计划前先问"几个人吃、预算多少"（忌口可选）。有答案（记忆库或当次输入）直接出计划。
2. **规则 B · 每类履约 2–3 个选项，按净省额排序**：自提/外送/不办卡各 2–3 个候选，最推荐第一 + 🏆 标注。
3. **规则 C · 套餐必须展开组成**：`query-meal-detail` 拉子项，卡片写清"里面有：主堡 + 小食 + 小食 + 饮料（默认搭配）"，可换子项写"+¥x 可换 y"——用户不查词典就能判断商品和价格。

README 场景 A 卡片同步为含组成行的新格式。
